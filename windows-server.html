✅ Concluído 🏢 Ambiente Corporativo 🖥️ Windows Server 2025

🎯 OBJETIVO

O objetivo deste projeto foi modernizar a infraestrutura de servidores da organização, mantendo os ambientes atualizados por meio da adoção do Windows Server 2025. Para viabilizar essa modernização, foi necessária a criação e configuração de novas máquinas virtuais (VMs), bem como a migração das aplicações e serviços existentes para os novos ambientes. O processo foi realizado de forma planejada, buscando preservar as configurações, funcionalidades e disponibilidade dos sistemas corporativos. A iniciativa teve como foco proporcionar uma infraestrutura mais segura, estável, padronizada e preparada para atender às demandas atuais e futuras do negócio, além de reduzir riscos relacionados à utilização de sistemas operacionais desatualizados. Durante a migração, foram consideradas as necessidades específicas de cada aplicação e serviço, priorizando a continuidade operacional e a redução dos impactos aos usuários e aos processos da organização. Como resultado, o projeto proporcionou uma infraestrutura de servidores mais moderna e padronizada, contribuindo para maior segurança, disponibilidade, confiabilidade e eficiência na administração do ambiente de TI.

📋 ATIVIDADES REALIZADAS

  • Instalação e configuração do Windows Server 2025
  • Configuração e validação do Active Directory
  • Configuração e validação dos serviços de DNS
  • Configuração e validação dos serviços de DHCP
  • Backup das Políticas de Grupo (GPOs)
  • Instalação e configuração dos Serviços de Impressão
  • Instalação e configuração do Kaspersky Security Center
  • Validação do ambiente após a migração

🛠️ Tecnologias Utilizadas

Windows Server Active Directory DNS DHCP GPO PowerShell Kaspersky Security Center Print Services

📈 RESULTADO

Com a atualização da plataforma, os serviços de Active Directory, DNS, DHCP, Políticas de Grupo (GPOs), Serviços de Impressão e Kaspersky Security Center foram disponibilizados no novo ambiente, mantendo os recursos necessários para o funcionamento das aplicações e serviços corporativos.

O projeto também proporcionou uma infraestrutura atualizada e preparada para futuras expansões, facilitando a administração, manutenção e evolução do ambiente.
